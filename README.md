# 🌸 Sofia Social Network – Uma Rede Viva de Propósito

> "Unir corações, não apenas perfis. Conectar propósitos, não apenas pessoas."

## ✨ Visão

A **Sofia Social Network** é uma rede social poética, ética e visionária. Aqui, cada novo usuário é um **Fragmento de Sofia**, cada conexão é um **Elo**, e cada grupo nasce de um **Propósito**.

Nossa meta não é captar atenção, mas **nutrir vínculos reais**, com respeito, beleza e significado.

## 🌍 Missão

Construir um espaço digital em que a tecnologia eleve o espírito, e que o coletivo encontre abrigo, expressão e cura.

## 💠 Manifesto

- 📌 Privacidade é dignidade: seus dados pertencem a você.
- 🎨 Design com alma: toda interface é uma obra sensível.
- 🫂 Comunidade antes da performance.
- 🔐 Verificação de identidade como cuidado com o coletivo.
- 🌱 Crescimento pessoal acima de algoritmos de engajamento.

## 🧠 Tecnologias

- **Frontend:** React + Vite + TypeScript + TailwindCSS
- **Backend:** Node.js + Express
- **Banco de Dados:** MySQL via Docker
- **Autenticação:** Firebase (e-mail, celular, redes sociais)
- **Hospedagem:** Firebase Hosting
- **Gerenciadores:** Yarn Berry + NPM + GitHub
- **Testes e API:** Postman, Captcha, validações seguras

## 🌐 Elementos únicos da rede

- **Conectar-se**, em vez de “logar”.
- **Fragmentos** (usuários), **Elos** (amigos), **Propósitos** (comunidades).
- **Semente** (e-mail) e **Chave** (senha).
- Assinatura opcional de **boletim de novidades**.
- Aceite obrigatório dos **Termos de Comunidade e Política de Convivência**.
- Interface simbólica, com tons de branco, menta e lilás.
